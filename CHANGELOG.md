# Changelog

## 1.0.0

- Initial release: click the selected Karma level again to lock Karma at it for the run.
- Server-side / host-only: players without the mod can join and play; players with it can also lock and see the badge.
- Lock badge on the lobby buttons, the lobby rule summary, the in-run Karma icon and the end-of-run report.
- `AllowClientLocking` config option and `karmalock_set` / `karmalock_status` console commands.
